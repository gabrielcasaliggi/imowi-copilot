# Contrato operativo propuesto para N1

1. Clasificar intención antes de iniciar preguntas.
2. Consultar sistemas disponibles antes de pedir datos que ya conoce el ISP.
3. Preguntar solamente campos necesarios para la rama activa.
4. Ejecutar únicamente acciones N1 aprobadas y reversibles.
5. Validar el resultado real; completar preguntas no equivale a resolver.
6. Cerrar como N1 solo con resultado confirmado.
7. Derivar a N2 con motivo, síntomas, pruebas, acciones y resultado.
8. Respetar solicitud explícita de agente y señales de seguridad.

Este contrato es propuesta de diseño; responsables N1/N2 deben aprobarlo.
